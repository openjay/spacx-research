## Approved wording

- **proposed / expected listing symbol SPCX**
- **anticipated listing on Nasdaq** (when citing S-1/A language)
- **pending Form 424B4 and first trading confirmation**

- “listed ticker SPCX”
- “listed equity SPCX”
- “publicly traded SPCX” (until post-listing)
